# Logic Gates Lab 
Інтерактивний симулятор логічних схем, де можна створювати, тестувати та дебажити цифрові схеми прямо у своєму браузері. Це "цифрова лабораторія" для студентів, викладачів та всіх, хто хоче глибше зануритися в логіку роботи комп’ютерів.

![image](https://github.com/user-attachments/assets/109c783b-72bf-4630-9ba1-c479fe06687f)

Переглянути робочу версію проєкту можна за посиланням:
[Logic Gates Lab](https://denysolkhovyknure.github.io/logic-gates-lab/)

# Чому це цікаво?

🔌 Створи власні схеми — додавати елементи, з’єднувати їх дротами та перевіряти, як вони працюють.

🎨 Свій дизайн для компонентів — можна використовувати будь-які зображення для створення кастомних вентилів.

📡 Симуляція в реальному часі — зміни на схемі миттєво відображаються без потреби в перезавантаженні.

📂 Збереження схем — можна зберігати їх у файл або інтегрувати автоматичне збереження на Google Drive.

🔄 Власні компоненти — є можливість розробляти та використовувати власні логічні блоки всередині схеми.

# Для кого це?

🎓 Студенти та викладачі — ідеальний інструмент для навчання цифровій логіці.

🔧 Ентузіасти електроніки — дозволяє тестувати ідеї без потреби у фізичних мікросхемах.

💻 Розробники ПЗ — розуміння логічних схем може допомогти в написанні оптимізованого коду.

# Технології

Проєкт працює у браузері, без потреби встановлення. 
Використані технології:

⚛️ JavaScript + React — сучасний фронтенд для швидкої та динамічної взаємодії. React працює з HTML, CSS та JavaScript для створення динамічного інтерфейсу.

🖼️ SVG — використовується для візуалізації схем, що дозволяє масштабувати та змінювати вигляд компонентів.

☁️ Google App Scripts — для автоматичного збереження та синхронізації даних із Google Drive. Конфігурації схем зберігаються у форматі JSON.

🌍 GitHub Pages — забезпечує безкоштовний хостинг та просте оновлення проєкту.
